第一章 初识智能体

定义与四要素 · 传统智能体演进 · LLM 新范式 · 运行原理 · 协作模式

1.1 什么是智能体
要点术语答案与解释
智能体的定义四要素

能通过传感器感知环境,并自主地通过执行器采取行动以达成特定目标的实体。

四个基本要素:

  • 环境 (Environment):智能体所处的外部世界(道路/金融市场等);
  • 传感器 (Sensors):感知能力的延伸(摄像头/雷达/API 数据流);
  • 执行器 (Actuators):改变环境的手段(机械臂等物理设备 / 调用服务等虚拟工具);
  • 自主性 (Autonomy):真正赋予「智能」的核心——能基于感知和内部状态独立决策,而非被动执行预设指令。
传统智能体演进阶梯反应式 → 模型 → 目标 → 效用 → 学习

一条「从简单到复杂、从被动反应到主动学习」的演进路线:

  • ① 反射智能体 (Simple Reflex):核心是「条件-动作」规则(自动恒温器)。只依赖当前感知,无记忆无预测,像数字化本能。
  • ② 基于模型的反射智能体 (Model-Based):有内部世界模型,追踪无法直接感知的方面,有初级「记忆」(隧道中的自动驾驶)。
  • ③ 基于目标的智能体 (Goal-Based):主动有预见地规划导向目标的行动(GPS 用 A* 算法规划路径)。
  • ④ 基于效用的智能体 (Utility-Based):为每个状态赋效用值,在多冲突目标间权衡,最大化期望效用(最短+最省油+避开拥堵)。
  • ⑤ 学习型智能体 (Learning Agent):含性能元件 + 学习元件,通过与环境互动自主学习修正策略;强化学习 (RL) 是其代表路径(AlphaGo Zero)。
LLM 驱动的新范式规划与推理 · 工具使用 · 动态修正

以 GPT 为代表的 LLM 改变了智能体的核心决策机制。传统智能体能力源于显式编程(确定、有边界);LLM 智能体靠海量数据预训练获得隐式世界模型与涌现能力(灵活、通用)。

以「智能旅行助手」为例,体现三点:

  • 规划与推理:把高层级目标分解为子任务(确认偏好→查询信息→制定行程→预订);
  • 工具使用:识别信息缺口,主动调用外部工具补全(调天气 API → 据雨天推荐室内活动);
  • 动态修正:把用户反馈(超预算)视为新约束,调整后续行动。

核心转变:从「编写代码」转向「引导一个通用的『大脑』去规划、行动、学习」。

分类维度①:内部决策架构反应式 / 模型式 / 目标 / 效用 + 学习元能力

依据内部决策架构的复杂程度(《人工智能:一种现代方法》):从反应式 → 模型式 → 基于目标 → 基于效用。学习能力是可赋予上述所有类型的「元能力」。

分类维度②:时间与反应性反应式 / 规划式 / 混合式

关注智能体是立即行动还是深思熟虑后规划。核心权衡:追求速度的反应性 vs 追求最优解的规划性。

  • 反应式 (Reactive):近乎即时响应、决策延迟低,感知→行动直接映射(安全气囊、高频交易)。优势是速度快开销低,代价是「短视」、易陷局部最优。
  • 规划式 (Deliberative):行动前用世界模型探索未来可能性,评估行动序列后果找最佳路径(棋手预想十几步)。优势是战略远见,代价是高昂的时间和计算成本。
  • 混合式 (Hybrid):结合两者。经典是分层设计(底层快速反应 + 高层审慎规划)。现代 LLM 智能体在「思考-行动-观察」循环中实现更灵活的混合。
分类维度③:知识表示符号主义 / 亚符号主义 / 神经符号主义

探究智能体用以决策的知识以何种形式存在——AI 领域半世纪辩论的核心:

  • 符号主义 (Symbolic AI):智能源于对符号的逻辑操作(规则库/知识图谱)。优势:透明可解释(金融医疗高风险领域重要);致命弱点「知识获取瓶颈」——依赖完备规则,现实世界新情况即失灵。
  • 亚符号主义 (Sub-symbolic / 连接主义):知识内隐分布在神经元网络中,从数据学统计模式(神经网络/深度学习)。优势:模式识别强、抗噪声;弱点是黑箱(无法解释为什么),纯逻辑推理差,会幻觉。
  • 神经符号主义 (Neuro-Symbolic):融合两者,既像神经网络学习、又像符号系统推理。类比卡尼曼《思考,快与慢》:
    • 系统 1:快速、直觉、并行 ≈ 亚符号(模式识别);
    • 系统 2:缓慢、有条理、基于逻辑 ≈ 符号(推理)。
    LLM 智能体是其绝佳范例:内核是神经网络,工作时却生成结构化中间步骤(思想/计划/API 调用这些符号)。
1.2 智能体的构成与运行原理
要点术语答案与解释
PEAS 模型任务环境定义

用 PEAS 精确描述一个任务环境:

  • Performance 性能度量(目标达成好坏的标准);
  • Environment 环境(外部世界);
  • Actuators 执行器(改变环境的手段);
  • Sensors 传感器(感知环境的途径)。
任务环境的复杂特性部分可观察 / 随机性 / 多智能体 / 序贯动态

LLM 智能体所处数字环境的特性,直接影响设计:

  • 部分可观察:无法一次获取全部信息(航班 API 只返回部分数据) → 需记忆和探索能力;
  • 确定性 vs 随机性:行动结果是否可预测。票价搜索是随机性环境(两次调用结果不同) → 需处理不确定性;
  • 多智能体 (Multi-agent):环境中有其他行动者(其他用户、调价脚本) → 需快速响应;
  • 序贯 + 动态:序贯=当前动作影响未来;动态=环境自身会变化 → 「感知-思考-行动-观察」循环须快速灵活适应。
智能体循环Agent Loop · 感知-思考-行动-观察

智能体通过一个持续循环与环境交互,这是其自主行为的基础。三阶段:

  • ① 感知 (Perception):通过传感器接收环境输入 = 观察 (Observation)(用户指令或上一步行动的反馈)。
  • ② 思考 (Thought):核心决策阶段(LLM 驱动),细分两环节:
    • 规划 (Planning):基于观察和记忆,更新理解,制定/调整行动计划,可能分解子任务;
    • 工具选择 (Tool Selection):从工具库选最适合下一步的工具及参数。
  • ③ 行动 (Action):通过执行器执行(调用代码解释器/搜索 API),改变环境状态。

行动引起环境状态变化,产生新的观察反馈,被下一轮感知捕获 → 持续闭环。

交互协议Thought / Action / Observation

为让 LLM 有效驱动循环,需明确的交互协议。智能体输出是结构化文本,含两部分:

  • Thought (思考):内部决策「快照」,用自然语言阐述如何分析情境、回顾观察、自我反思、规划下一步。
  • Action (行动):基于思考决定的具体操作,通常为函数调用。
Thought: 用户想知道北京天气。我需要调用天气查询工具。 Action: get_weather("北京")

解析器 (Parser)捕捉 Action 指令调用对应函数;返回的原始数据(如 JSON)被封装成简洁自然语言 Observation,作为下一轮输入。

1.3 动手体验:5 分钟实现第一个智能体
要点术语答案与解释
提示工程指令模板 / system_prompt

驱动真实 LLM 的关键是提示工程:设计一个「指令模板」,告诉 LLM 它的角色、拥有的工具、如何格式化思考和行动,作为 system_prompt 传入。

模板要点:声明可用工具及签名;规定输出格式(Thought: ... Action: ...);Action 形式为「调用工具 function_name(arg="value")」或「结束任务 Finish[最终答案]」;每次只输出一对 Thought-Action。

工具(Tool)

工具是智能体与外部世界交互的「执行器」。本例两个工具:

  • get_weather(city):调 wttr.in API 返回 JSON,格式化为自然语言;
  • get_attraction(city, weather):调 Tavily Search API 搜索景点推荐。

所有工具函数放入字典 available_tools 供主循环调用。

接入 LLMOpenAI 兼容接口 · 三凭证

许多 LLM 服务商(OpenAI/Azure/Ollama/vLLM)都遵循兼容 OpenAI 的接口规范,带来标准化便利。实现通用客户端 OpenAICompatibleClient 可连任何兼容服务。

实例化需三信息:API_KEY、BASE_URL、MODEL_ID。其 generate(prompt, system_prompt) 方法构造 system+user 消息调用 chat completions 接口。

执行行动循环主循环四步 · 最大循环次数

主循环整合所有组件,驱动 LLM 决策。每轮:

  • ① 构建 prompt(拼接历史);
  • ② 调 LLM 思考,正则截断多余的 Thought-Action 对;
  • ③ 解析 Action:若 Finish[…] 则输出最终答案并 break;否则正则提取工具名和参数,从 available_tools 调用;
  • ④ 记录 Observation 追加到历史,进入下一轮。

设置最大循环次数(如 5)是必要的防护:防止智能体陷入无限循环/反复调用工具。

核心是「工具」+「提示工程」的结合——这正是主流框架(LangChain/LlamaIndex)的设计精髓。

智能体四项基本能力任务分解 / 工具调用 / 上下文理解 / 结果合成

旅行助手案例演示了基于 Thought-Action-Observation 范式的四项能力:任务分解、工具调用、上下文理解、结果合成。通过循环不断迭代,把模糊意图转化为具体可执行步骤并达成目标。

1.4 智能体应用的协作模式
要点术语答案与解释
作为开发者工具Copilot · Claude Code · Trae · Cursor

智能体作为强大辅助工具增强而非取代开发者,自动化繁琐重复任务。代表产品:

  • GitHub Copilot:GitHub+OpenAI,深度集成 VS Code,以代码自动补全闻名,有 Copilot Chat 对话编程;
  • Claude Code:Anthropic,终端中用自然语言编码,理解完整代码库,支持 headless 无交互模式(CI/hooks/脚本);
  • Trae:新兴工具,智能代码生成与优化,轻量快速响应,适合频繁迭代/原型;
  • Cursor:AI 原生代码编辑器(非插件),设计之初就以 AI 交互为核心,强调让 AI 理解整个代码库上下文。
作为自主协作者目标-委托 · 三种架构范式

把高层级目标委托给智能体,它像项目成员独立规划、推理、执行、反思直到交付。关系从「命令-执行」演变为「目标-委托」。代表框架:BabyAGI、AutoGPT、CrewAI、AutoGen、MetaGPT、LangGraph。三种主流架构范式:

  • ① 单智能体自主循环(如 AgentGPT):通用智能体通过「思考-规划-执行-反思」闭环自我提示迭代;
  • ② 多智能体协作(最主流):模拟人类团队。细分:
    • 角色扮演式对话(CAMEL):为两个智能体设角色和沟通协议;
    • 组织化工作流(MetaGPT/CrewAI):模拟分工明确的虚拟团队(软件公司/咨询小组),各有职责和 SOP;AutoGen/AgentScope 提供更灵活的交互网络。
  • ③ 高级控制流架构(LangGraph):把执行过程建模为状态图 (State Graph),灵活可靠地实现循环、分支、回溯、人工介入。
Workflow vs Agent按部就班 vs 自主达成

一句话:Workflow 是让 AI 按部就班执行指令,Agent 是赋予 AI 自由度去自主达成目标。

  • Workflow(工作流):对任务预先定义、结构化编排的精确静态流程图。例:费用报销审批(金额分支判断),每步每条件都预先设定。
  • Agent(智能体):具备自主性、以目标为导向的系统,能理解环境、推理、制定计划、动态行动。LLM 扮演「大脑」。例:旅行助手——无写死的 if 天气=晴天 then 推荐颐和园 规则,而是基于实时信息动态推理决策(雨天则推荐室内场所)。

核心价值:Agent 基于实时信息动态推理和决策的能力。

第二章 智能体发展史

符号主义 · 专家系统 · ELIZA · 心智社会 · 联结/强化/预训练 · LLM 智能体

2.1 基于符号与逻辑的早期智能体
要点术语答案与解释
符号主义 (Symbolicism)逻辑AI / 传统AI

AI 的第一个重要范式。核心信念:智能行为的核心是基于一套明确规则对符号进行操作。智能体是「物理符号系统」——用内部符号表示外部世界,通过逻辑推理规划行动。「智慧」完全来源于设计者预先编码的知识库和推理规则,而非自主学习。

物理符号系统假说 (PSSH)Newell & Simon 1976 · 两大论断

符号主义时代的理论基石。大胆宣称:智能的本质,就是符号的计算与处理。两个核心论断:

  • 充分性论断:任何物理符号系统,都具备产生通用智能行为的充分手段;
  • 必要性论断:任何能展现通用智能行为的系统,其本质必然是物理符号系统。

物理符号系统 = 一组可区分的符号 + 一系列对符号操作的过程(创建/修改/复制/销毁符号结构)。深远影响:把对「心智」的哲学研究转化为可工程化实现的具体问题。

专家系统 (Expert System)知识库 + 推理机

符号主义最重要、最成功的应用。核心目标:模拟人类专家在特定领域解决问题的能力。体现知识与推理相分离的设计思想(符号主义重要特征)。两大核心组件:

  • 知识库 (Knowledge Base):存放专家知识。常用知识表示方法是产生式规则 (Production Rules)——一系列「IF-THEN」条件语句。
  • 推理机 (Inference Engine):核心计算引擎,根据事实在知识库找规则推导结论。两种工作方式:
    • 正向链 (Forward Chaining):从已知事实出发,匹配 IF 触发 THEN,直至推出目标。数据驱动;
    • 反向链 (Backward Chaining):从假设目标出发,反推需要的子目标,递归证明。目标驱动。
MYCIN反向链 · 置信因子 CF

史上最著名的专家系统之一(斯坦福,1970s),辅助诊断细菌性血液感染、推荐抗生素。

  • 工作原理:问答式交互收集症状;知识库约 600 条 IF-THEN 规则;推理机主要用反向链(从「确定致病菌」目标反推证据)。
  • 不确定性处理:重要创新 置信因子 (Certainty Factor, CF)——用 −1 到 1 的数值表示结论可信度,比布尔逻辑更贴近现实。
  • 成就:血液感染诊断表现超非专业医生、达专家水平,雄辩证明 PSSH 有效性,为 AI 商业化铺路。
SHRDLU积木世界 · 综合性智能典范

Winograd 1968-1970 开发。在「积木世界」(含积木和虚拟机械臂的三维空间)中用自然语言流畅交互的综合性智能体。首次将多个 AI 模块(语言解析/规划/记忆)集成于统一系统并协同。三大能力:

  • 自然语言理解:解析复杂歧义句,支持指代消解(the one you are holding)和上下文记忆;
  • 规划与行动:自主规划动作序列(先移开绿积木再放蓝积木);
  • 记忆与问答:能问世界状态、行为历史、甚至行为动机(Why? → BECAUSE YOU ASKED ME TO)。

历史地位:综合性智能典范;普及微观世界研究方法;其能力局限于积木世界也引发对「符号处理 vs 真正理解」的长期思辨。

符号主义的根本挑战知识获取瓶颈 · 常识 · 框架 · 脆弱性

从微观世界走向开放现实世界时遇到的两大类固有难题:

（1）常识知识与知识获取瓶颈

  • 知识获取瓶颈:知识需专家+知识工程师繁琐访谈提炼编码,成本高、难规模化;专家的内隐直觉知识很难表达为 IF-THEN。
  • 常识问题:人类依赖庞大常识背景(水是湿的),符号系统除非明确编码否则一无所知。Cyc 项目历经数十年成效有限。

（2）框架问题与系统脆弱性

  • 框架问题 (Frame Problem):动态世界中,执行动作后如何高效判断哪些事物未变是逻辑难题;显式声明所有不变状态计算上不可行。
  • 系统脆弱性 (Brittleness):完全依赖预设规则,遇到规则外微小变化即完全失灵,无法像人类灵活变通。SHRDLU 之成功正因运行在规则完备的封闭世界。
2.2 构建基于规则的聊天机器人
要点术语答案与解释
ELIZAWeizenbaum 1966 · DOCTOR 脚本

MIT 的 Weizenbaum 1966 发布,早期 NLP 著名尝试。是一个可执行不同「脚本」的框架,最成功的脚本是 DOCTOR,模仿罗杰斯学派非指导性心理治疗师。

设计思想:从不正面回答或提供信息,而是识别用户输入中的关键词,应用预设转换规则,把陈述转成开放式提问。魏泽鲍姆本意是证明:用简单句式转换,机器在完全不理解内容的情况下能营造「智能/共情」的假象。却意外引发「ELIZA 效应」——许多人深信它能理解自己。

模式匹配与文本替换四步算法

ELIZA 算法基于模式匹配 + 文本替换,四步:

  • ① 关键词识别与排序:为每个关键词设优先级,输入含多个关键词时选最高优先级规则;
  • ② 分解规则:用带通配符 * 的规则捕获句子其余部分(如 * my *);
  • ③ 重组规则:从关联的一组重组规则中(通常随机)选一条生成回应,可用上一步捕获内容;
  • ④ 代词转换:重组前做简单代词转换(I→you, my→your)维持连贯。

本质:把复杂 NLP 问题简化为可操作的、基于规则的模式匹配游戏。

规则驱动系统的局限无语义理解 · 无状态 · 规则爆炸

ELIZA 实践直接印证了 2.1.4 的符号主义挑战,三大局限:

  • 缺乏语义理解:不理解词义。I am not happy 仍机械匹配 I am (.*) 生成语义不通回应(不懂否定词 not);
  • 无上下文记忆:系统是无状态 (Stateless),每次回应只基于当前单句,无法连贯多轮对话;
  • 规则扩展性问题:增加规则导致规则库规模爆炸,规则间冲突与优先级管理极复杂,最终难以维护。

核心矛盾:看似智能的表现完全依赖预先编码的规则;面对真实语言无限可能性,穷举式方法注定不可扩展——没有真正理解,只在执行符号操作,这正是脆弱性根源。

2.3 马文·明斯基的心智社会
要点术语答案与解释
对单一整体智能的反思Top-down 中央处理器的失败

符号主义局限日益明显:专家系统无儿童常识、SHRDLU 困于积木世界、ELIZA 对内容一无所知。它们都遵循自上而下 (Top-down) 设计:一个全知全能的中央处理器按统一逻辑规则决策。

明斯基提出根本问题:「理解」是单一能力还是数十种心智过程的协同?「常识」是百万条规则的庞大知识库,还是分布式经验网络?是否应承认智能是「不完美」的、由功能各异甚至冲突的简单部分组成的大杂烩?强行把多样化心智塞进僵化逻辑框架,正是早期 AI 停滞的根源。

名言:「让我们智能的神奇戏法是什么?戏法就是没有戏法。智能的力量源于我们巨大的多样性,而非任何单一完美的原则。」

心智社会 (Society of Mind)Agent / Agency / 涌现

明斯基不再把心智当金字塔层级,而是看作扁平化、充满互动协作的「社会」。三个关键概念:

  • 智能体 (Agent):极简单、专门化的心智过程,自身「无心」(如识别线条的 LINE-FINDER、抓握的 GRASP);
  • 机构 (Agency):一组协同工作的智能体,完成更复杂任务(如搭积木的 BUILD 由 SEE/FIND/GET/PUT 组成),通过去中心化的激活与抑制信号相互影响;
  • 涌现 (Emergence):复杂有目的的智能行为,并非高级智能体预先规划,而是从大量简单底层智能体的局部交互中自发产生。

积木塔例:目标激活 BUILD-TOWER → BUILDER(循环)→ ADD-BLOCK → FIND/GET/PUT → 更底层 SEE-SHAPE/REACH/GRASP。没有任何智能体拥有全局规划,但通过简单激活抑制规则,搭塔行为自然涌现。

对多智能体系统的启发去中心化 / 涌现式计算 / 社会性

心智社会为分布式 AI (DAI) 和多智能体系统 (MAS) 提供了重要概念基础。核心追问:心智内部智能靠大量简单智能体协作涌现,那么多个物理上分离的计算实体间,是否也能协作涌现出更强的「群体智能」?三方面直接启发 MAS:

  • 去中心化控制:不存在中央控制器 → MAS 继承,研究无中心节点的协调机制和任务分配;
  • 涌现式计算:复杂解可从简单局部交互自发产生 → 启发蚁群算法、粒子群优化等;
  • 智能体的社会性:强调交互(激活/抑制)→ MAS 扩展为研究通信语言(ACL)、交互协议(契约网)、协商、信任、组织结构,正式开启 MAS 研究序幕。
2.4 学习范式的演进与现代智能体
要点术语答案与解释
联结主义 (Connectionism)三大核心思想

对符号主义局限的直接回应,20世纪80年代重新兴起。自下而上的方法,灵感来自生物大脑神经网络。核心思想:

  • 知识的分布式表示:知识不以符号/规则存于知识库,而以连接权重形式分布式存储在大量简单处理单元(人工神经元)的连接间;
  • 简单的处理单元:每个神经元只做简单计算(加权输入 → 激活函数 → 输出);
  • 通过学习调整权重:智能来自「学习」——接触大量样本,按算法(如反向传播)自动迭代调整权重,使输出接近目标。

根本转变:符号主义把人类知识显式编码给机器;联结主义则创造能像人类一样学习知识的机器。深度学习成功为智能体赋予强大感知和模式识别能力。

强化学习 (RL)五要素 · 感知-行动-学习闭环 · 累积奖励

专注解决序贯决策问题。不直接从标注静态数据学,而是通过与环境的直接交互在「试错」中学习如何最大化长期收益(AlphaGo 自我对弈是经典)。

五要素:智能体(学习者/决策者)、环境(交互对象)、状态 S(环境某时刻描述,决策依据)、行动 A(可采取的操作)、奖励 R(评价行动好坏的标量信号)。

闭环:① 观察状态 S_t → ② 据策略 π(状态到行动的映射)选行动 A_t 执行 → ③ 环境转到新状态 S_{t+1} → ④ 反馈即时奖励 R_{t+1} → ⑤ 用反馈更新优化策略。

学习目标:非最大化即时奖励,而是最大化从当前到未来的累积奖励(回报 Return)——需有「远见」,可能牺牲眼前奖励换未来更大奖励(围棋弃子)。

预训练 (Pre-training)预训练-微调范式 · 自监督学习

解决 RL 智能体「从零开始、缺先验知识」的问题。方案在 NLP 领域浮现,核心是基于大规模数据的预训练。预训练-微调范式两步:

  • ① 预训练阶段:在互联网级海量文本上,用自监督学习训练超大规模神经网络。目标非特定任务,而是学语言内在规律、语法、事实、上下文逻辑(最常见目标:「预测下一个词」);
  • ② 微调阶段:针对下游任务,用少量标注数据微调模型适应任务。

意义:传统 NLP 为单一任务从零训练(知识面窄、难泛化、需大量标注);预训练范式彻底改变现状。

LLM 的涌现能力上下文学习 · 思维链

在数万亿 token 上预训练,LLM 权重构建了世界知识的隐式模型,以全新方式解决了符号主义最棘手的「知识获取瓶颈」。规模跨越阈值后展现涌现能力:

  • 上下文学习 (In-context Learning):不调权重,仅在输入提供几个示例(Few-shot)甚至零示例(Zero-shot)就能完成新任务;
  • 思维链 (CoT) 推理:引导模型在回答复杂问题前先输出一步步推理,显著提升逻辑/算术/常识推理准确性。

标志:LLM 不再只是语言模型,演变成兼具海量知识库 + 通用推理引擎双重角色的组件。

LLM 驱动的智能体四大核心组件 · 闭环工作流

以 LLM 为核心的智能体是新范式,能感知、规划、决策、执行。四大核心组件(协同的持续迭代闭环):

  • ① 感知模块:从环境接收原始输入形成观察;
  • ② 规划模块 + LLM(认知核心):规划模块用反思 (Reflection)和自我批判 (Self-criticism)分解目标;LLM 与记忆模块交互整合历史,深度推理决策下一步(常为工具调用);
  • ③ 执行模块:解析指令,从工具箱选合适工具(代码执行器/搜索/API)与环境交互 = 行动;
  • ④ 记忆模块:行动产生工具结果和新环境状态构成新观察,LLM 据此更新记忆,启动下一轮「感知-思考-行动」循环。
三大思潮 / 发展节点符号主义 / 联结主义 / 行为主义

AI 体发展是三大核心思想流派半个多世纪交织、竞争、融合的历程:

  • 符号主义 (Symbolism):Simon、Minsky 代表,智能核心在对符号的操作与逻辑推理。催生 SHRDLU、专家系统、国际象棋「深蓝」;
  • 联结主义 (Connectionism):灵感源于大脑神经网络。Hinton 等推动反向传播奠定复苏基础,深度学习时代(CNN/Transformer)成主流;
  • 行为主义 (Behaviorism):强调与环境互动试错学最优策略,现代化身为强化学习。从 TD-Gammon 到击败人类的 AlphaGo。

融合:2020s 起三大思潮深度融合——GPT 系列本身是联结主义产物,却成为执行符号推理、工具调用、规划决策的核心「大脑」,形成神经-符号结合的现代智能体架构。

第三章 大语言模型基础

N-gram→RNN→LSTM→Transformer→Decoder-Only · 提示工程·分词 · 缩放法则·幻觉

3.1 语言模型与 Transformer 架构
要点术语答案与解释
语言模型的根本任务

计算一个词序列(句子)出现的概率——判断什么样的句子通顺、自然。它是智能体理解指令、生成回应的基础。

概率的链式法则→ 引出为什么需要 N-gram

句子概率 = 每个词的条件概率连乘:

P(S) = P(w₁)·P(w₂|w₁)·P(w₃|w₁,w₂)⋯P(wₘ|w₁,…,wₘ₋₁)

直接计算几乎不可能:像 P(wₘ|w₁,…,wₘ₋₁) 这样的长条件概率,词序列可能从未在语料中出现。

N-gram马尔可夫假设 · Bigram · Trigram · MLE

核心思想:基于「马尔可夫假设」——不必回溯全部历史,近似认为一个词只与前面有限的 n−1 个词有关。N 代表上下文窗口大小。

  • Bigram (N=2):一个词只与前 1 个词有关 → P(wᵢ|w₁..wᵢ₋₁) ≈ P(wᵢ|wᵢ₋₁)
  • Trigram (N=3):只与前 2 个词有关 → P(wᵢ|…) ≈ P(wᵢ|wᵢ₋₂,wᵢ₋₁)

概率用「最大似然估计 MLE」靠计数估算:P(wᵢ|wᵢ₋₁) = Count(wᵢ₋₁,wᵢ) / Count(wᵢ₋₁)。

两大缺陷:① 数据稀疏性(未出现序列概率为 0,需平滑);② 泛化能力差(把词当孤立符号,不懂 agent 与 robot 语义相近)。

词嵌入 (Word Embedding)神经网络语言模型 · 余弦相似度

2003 年 Bengio 的「前馈神经网络语言模型」里程碑:把每个词映射为高维连续空间中的一个点 = 词嵌入。语义相近的词向量位置相近。

两步思想:① 构建语义空间(词嵌入);② 学习「上下文 → 下一个词概率分布」的映射函数。

用余弦相似度度量:

sim(a,b) = (a·b) / (|a|·|b|) ,取值 [−1, 1]

经典类比:vec(King) − vec(Man) + vec(Woman) ≈ vec(Queen)。解决了 N-gram 泛化差问题,但仍保留固定上下文窗口的限制。

RNN隐藏状态 · 长期依赖 · 梯度消失/爆炸

循环神经网络核心思想:为网络增加「记忆」,打破固定窗口。

引入隐藏状态 (hidden state)= 网络的短期记忆。每步:读当前输入 + 上一刻记忆 → 生成新记忆向后传,信息在序列中持续传递。

致命问题:长期依赖问题。序列长度即网络深度,反向传播时梯度多次连乘 →

  • 梯度消失:梯度趋向 0,学不到早期信息;
  • 梯度爆炸:梯度变得极大。
LSTM细胞状态 · 遗忘门 · 输入门 · 输出门

长短时记忆网络专为解决长期依赖而设计。两大核心创新:

  • 细胞状态 (Cell State):独立于隐藏状态的信息通路,信息在时间步间更顺畅传递。
  • 门控机制:由几个小网络构成,有选择地放行信息,控制细胞状态的增删。三个门:

① 遗忘门:决定从上一时刻细胞状态丢弃哪些信息;
② 输入门:决定把当前输入的哪些新信息存入细胞状态;
③ 输出门:决定据当前细胞状态输出哪些信息到隐藏状态。

Transformer为什么取代 RNN · Encoder-Decoder

2017 年 Google 提出。RNN 必须按顺序串行处理(第 t 步要等第 t−1 步),无法大规模并行,限制规模和训练速度。

Transformer 完全抛弃循环结构,只靠注意力机制捕捉依赖,实现真正的并行计算。为机器翻译设计,宏观遵循编码器-解码器 (Encoder-Decoder):

  • 编码器:「理解」整个输入,为每个词元生成富含上下文的向量;
  • 解码器:「生成」目标,参考已生成前文 + 询问编码器结果。
QKV自注意力 · 缩放点积公式

自注意力建模「读句子时把注意力分配到相关词上」的现象。为每个词引入三个可学习角色(各由词嵌入乘权重矩阵得到):

  • 查询 Query (Q):当前词主动查询别的词;
  • 键 Key (K):可被查询词的「标签/索引」;
  • 值 Value (V):词本身携带的「内容/信息」。

四步:① 算相关性(Q 与所有 K 点积) → ② 稳定化(÷√dₖ) → ③ Softmax 归一化 → ④ 权重 × V 加权求和。

Attention(Q,K,V) = softmax( QKᵀ / √dₖ ) V
多头注意力

单头只学一种关联。多头把 Q/K/V 在维度上切分成 h 份,各做一次单头注意力,拼接后线性变换整合——如同 h 个「专家」从不同角度(指代/时态/从属等)审视句子,大幅增强表达能力。

前馈神经网络Position-wise FFN

逐位置前馈网络作用:从注意力聚合的信息中提取更高阶特征。

「逐位置」= 独立作用于序列每个词元,所有位置共享同一组权重。结构:两个线性变换 + 一个 ReLU,「先扩大再缩小」(d_ff ≈ 4×d_model)。

FFN(x) = max(0, xW₁+b₁) W₂ + b₂
残差连接Add · 解决梯度消失

残差连接 (Add):把子模块输入直接加到输出上 → Output = x + Sublayer(x)。

反向传播时梯度可绕过子模块直接前传,解决了深度网络的梯度消失问题,即使很深也能有效训练。

层归一化Norm · 内部协变量偏移

层归一化 (Norm):对单个样本的所有特征归一化(均值 0、方差 1)。

解决训练中的内部协变量偏移,使每层输入分布稳定,加速收敛、提高稳定性。与残差一起组成 Add & Norm 包裹每个子模块。

位置编码Positional Encoding · sin/cos

自注意力本身不含任何顺序/位置信息(对它 "agent learns" 与 "learns agent" 等价)。

位置编码 = 为每个词元嵌入加上一个代表其位置的位置向量。该向量不是学习的,而是固定公式算出:

PE(pos,2i) = sin(pos / 10000^(2i/d_model)) PE(pos,2i+1) = cos(pos / 10000^(2i/d_model))

效果:相同词因位置不同 → 加不同位置编码 → 变得独一无二。(pos=位置,i=维度索引)

Decoder-OnlyGPT · 自回归 · 掩码自注意力

GPT 的简化思想:语言核心任务就是预测下一个词。于是完全抛弃编码器,只留解码器 → Decoder-Only。GPT-4/Llama 等均基于此。

自回归 (Autoregressive):给起始文本 → 预测下一词 → 把新词加到输入末尾 → 再预测 → 重复,像「文字接龙」。

掩码自注意力:训练时分数算完后、Softmax 前用「因果掩码」把当前位置之后的分数置为极大负数,Softmax 后概率为 0,防止模型「偷看」未来答案;保证训练方式与生成时的自回归一致。

三大优势:① 训练目标统一(只预测下一词,适合海量无标注预训练);② 结构简单易扩展;③ 天然适合生成任务。

3.2 与大语言模型交互
要点术语答案与解释
top-k

按概率从高到低排序,只取前 k 个 token 组成候选集,归一化后再采样。k=1 时退化为贪心采样(完全确定)。

与温度的区别:温度调分布陡峭(候选数不变),top-k 限制候选数量。

top-p核采样 Nucleus

按概率排序后逐步累加,累加和首次 ≥ p 的最小集合即「核集合」,归一化后采样。

相对固定截断的 top-k,top-p 能动态适应长尾,对不均匀分布适应性更好。通常 top-k 与 top-p 二选一。

温度 Temperature采样参数总览 · 协同优先级

采样参数本质:调整模型对概率分布的采样策略(基于 Softmax)。温度控制随机性 vs 确定性:

pᵢ^(T) = e^(zᵢ/T) / Σ e^(zⱼ/T)

T 小→分布更陡峭→更保守/确定;T 大→更平坦→更多样/可能不连贯。三档场景:

  • 低温 (0≤T<0.3):精准确定 → 问答/数据计算/代码/法律条文;
  • 中温 (0.3≤T<0.7):平衡自然 → 日常对话/客服/邮件文案;
  • 高温 (0.7≤T<2):创新发散 → 诗歌/科幻/slogan/灵感。

三参数协同优先级:温度调整 → top-k → top-p。边界:T=0 时 top-k/p 失效;top-k=1 时温度/p 失效。

零样本 / 单样本 / 少样本Zero / One / Few-shot

按提供「示例 (Exemplar) 数量」分类(以情感分类为例):

  • 零样本:不给任何示例,直接下指令(依赖预训练泛化);
  • 单样本:给 1 个完整示例,展示格式与输出风格;
  • 少样本:给多个示例,让模型理解任务细节/边界/细微差别。
指令调优Instruction Tuning · 文本补全 vs 指令

早期 GPT-3 是「文本补全」模型,不擅长理解执行指令。指令调优= 用大量「指令-回答」数据微调预训练模型,使其能遵循指令。现今 ChatGPT/DeepSeek/Qwen 都是经指令调优的版本。

对比:文本补全模型需用少样本「教会」它;指令调优模型可直接下达自然语言指令。

基础提示词技巧角色扮演 · 上下文示例
  • 角色扮演 (Role-playing):赋予特定角色 → 引导回答风格/语气/知识范围(如「你是一位资深 Python 专家…」)。
  • 上下文示例 (In-context Example):同少样本思想,提供清晰输入输出示例,复杂格式/特定风格任务尤其有效(如指定 JSON 输出格式)。
COT思维链 Chain-of-Thought

适用场景:逻辑推理/计算/多步骤思考的复杂问题。核心做法:引导模型「一步一步思考」(加引导语如 "Let's think step by step")。

价值:既提升复杂任务正确率,也使回答更可信、更易检查纠正(显式展示推理过程)。

分词 / 词元Tokenization · Token

计算机只能理解数字。分词= 把文本序列转成数字序列的过程;分词器 (Tokenizer)按规则把文本切成最小单元词元 (Token)。

为何不用「字符」或「单词」:

  • 按词:词表爆炸 + 未登录词(OOV);语义关联缺失(look/looks/looking 视为不同词);
  • 按字符:词表小、无 OOV,但单字符无独立语义,学习效率低。

现代 LLM 主流:子词分词——常见词保留完整,罕见词拆成有意义子词片段,兼顾词表大小与语义。

BPEWordPiece · SentencePiece

BPE (字节对编码)——GPT 系列采用,核心是「贪心合并」:

  • ① 初始化:词表 = 语料所有基本字符;
  • ② 迭代合并:统计相邻词元对频率,合并最高频对成新词元入词表;
  • ③ 重复直到词表达阈值。

BPE 的两个主要变体:

  • WordPiece(Google BERT):合并标准非「最高频率」,而是「最大化提升语料库语言模型概率」(优先合并让整体更通顺的对);
  • SentencePiece(Google 开源,Llama 采用):把空格也当普通字符(下划线 _ 表示),分词/解码完全可逆、不依赖特定语言(无需知道中文不用空格)。
分词器对开发者的意义上下文窗口 · API成本 · 模型异常
  • 上下文窗口限制:窗口(8K/128K)以 Token 数量计(非字符数/单词数);中英文、不同分词器 Token 数差异大。精确管理输入长度是构建长时记忆智能体的基础。
  • API 成本:多数模型按 Token 数计费,了解分词方式是预估/控制成本的关键。
  • 模型表现的异常:分词陷阱影响鲁棒性。例:2 + 2 能算但 2+2(无空格)可能出错(被切成罕见词元);同一词大小写不同 → 切成完全不同 Token 序列。
本地部署开源模型Hugging Face · Qwen1.5-0.5B · 调用流程

用 Hugging Face Transformers 标准化加载预训练模型。示例模型 Qwen/Qwen1.5-0.5B-Chat(阿里 ~5亿参数,适合入门本地部署)。

两个核心类:AutoModelForCausalLM(加载权重)、AutoTokenizer(加载分词器)。

调用四步:① apply_chat_template 格式化对话(system/user 角色) → ② tokenizer 编码文本为 Token ID → ③ model.generate() 生成(max_new_tokens 控制长度) → ④ tokenizer.decode() 把 Token ID 翻译回文本。

模型选型关键考量八大维度
  • ① 性能与能力:参考 LMSys Chatbot Arena 等排行榜;
  • ② 成本:闭源=API 按 Token 计费;开源=本地硬件+运维;
  • ③ 速度(延迟):实时交互(客服/NPC)需低延迟;
  • ④ 上下文窗口:长文档/代码库/长期对话需大窗口(128K+);
  • ⑤ 部署方式:API 简便但数据出第三方;本地保隐私但要求高;
  • ⑥ 生态与工具链:社区/教程/微调工具/LangChain/LlamaIndex;
  • ⑦ 可微调性与定制化:能否用自有数据定制(开源通常更灵活);
  • ⑧ 安全性与伦理:偏见/毒性/幻觉及负责任 AI。
闭源 vs 开源模型代表模型 · MoE

闭源(技术前沿 + 稳定 API):

  • OpenAI GPT:GPT-3→ChatGPT(引入 RLHF 对齐)→GPT-4(多模态)→GPT-5;
  • Google Gemini:原生多模态、超长上下文,分 Ultra/Pro/Nano,2.5 含 Pro 与 Flash;
  • Anthropic Claude:以 AI 安全为首,长文档/减害/指令可靠,企业级青睐;Claude 3 分 Opus/Sonnet/Haiku;
  • 国内:文心一言/混元/盘古/星火/月之暗面。

开源(灵活/透明/可微调):

  • Meta Llama:Llama 4(2025.4)首批采用 MoE(混合专家) 架构(仅激活所需部分提效);含 Scout(1000万 token 上下文)/Maverick(多模态)/Behemoth(最强);
  • Mistral AI:法国,「小尺寸高性能」;
  • 国内:通义千问 Qwen、ChatGLM。

缩放法则Scaling Laws · 幂律

揭示模型性能与三要素呈可预测的幂律关系(对数-对数坐标下平滑):① 模型参数量 ② 训练数据量 ③ 计算资源(算力)。

指导意义:按比例持续增加三要素 → 性能可预测、平滑提升,无明显瓶颈。

Chinchilla 定律最优配比 · 纠正「越大越好」

2022 年 DeepMind 提出的重要修正:纠正了「越大越好」的片面认知。

核心结论:给定计算预算下,参数量与数据量存在最优配比——最优模型应「更小但用更多数据」训练。案例:700 亿 Chinchilla 用 4 倍数据训练,性能反超 1750 亿 GPT-3。

能力涌现Emergence

规模达阈值后突然展现小模型完全没有的新能力。典型涌现能力:链式思考(CoT)、指令遵循、多步推理、代码生成(数百亿~千亿参数后才显著)。

对开发者:实现复杂自主决策/规划,前提是选足够大规模的模型。

模型幻觉Hallucination · 定义与三类

幻觉= 生成内容与客观事实/用户输入/上下文矛盾,或编造不存在的事实/实体/事件(过度自信地「编造」)。三类:

  • 事实性幻觉 (Factual):与现实世界事实不符;
  • 忠实性幻觉 (Faithfulness):摘要/翻译等未忠实反映源文本;
  • 内在幻觉 (Intrinsic):生成内容与输入信息直接矛盾。

成因:① 训练数据含错误/矛盾;② 自回归机制只预测下一词、无内置事实核查;③ 复杂推理逻辑链出错。另有知识时效性不足、训练数据偏见等挑战。

幻觉缓解方法数据/模型/推理三层 · RAG · 工具
  • 数据层面:高质量数据清洗、引入事实性知识、RLHF(强化学习+人类反馈);
  • 模型层面:探索新架构、让模型表达不确定性;
  • 推理与生成层面(三种主流):
    • RAG(检索增强生成):生成前从外部知识库检索相关信息作为上下文,引导生成基于事实的回答(最有效之一);
    • 多步推理与验证:每步自我检查或外部验证;
    • 引入外部工具:调用搜索引擎/计算器/代码解释器获取实时信息或精确计算。
